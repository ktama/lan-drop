# LAN Drop

LAN内で一時的にファイルを共有するための軽量HTTPサーバー。管理者権限不要、ブラウザのみで利用可能。

## 特徴

- 🔒 **Capability URL** - 24文字のトークン付きURLで安全にアクセス
- 📂 **ファイル共有** - ディレクトリ内のファイルを一覧・ダウンロード
- 📤 **アップロード対応** - ブラウザからドラッグ&ドロップでアップロード（進捗表示付き）
- 📱 **QRコード** - 起動時とブラウザ画面に共有URLのQRコードを表示
- ⏱️ **自動停止** - TTL/アイドルタイムアウトで自動シャットダウン
- 🌐 **IP制限** - CIDR表記で接続元を制限可能
- 📋 **JSONLログ** - アクセスログを構造化形式で記録
- 📦 **単一exe** - 依存なしの自己完結型実行ファイル

## クイックスタート

```powershell
# 特定のディレクトリを共有
lan-drop.exe --dir C:\Share

# カレントディレクトリを共有
lan-drop.exe --dir .

# 読み取り専用モード
lan-drop.exe --dir C:\Share --readonly
```

起動すると以下のような出力が表示されます：

```
LAN Drop v1.1.0
============================================================
  Root:     C:\Share
  URL:      http://192.168.1.10:8000/abc123def456ghi789jkl012/
  Token:    abc123def456ghi789jkl012 (auto-generated)
  TTL:      60 minutes
  Idle:     30 minutes
  Log:      <exe>\log\lan-drop.log

  （ここに URL の QR コードが表示されます）
============================================================
  Press Ctrl+C to stop.
```

ネットワークの種類が「パブリック」の場合や、短いトークンを指定した場合は、`Warning:` の行で注意を表示します。

複数のネットワークインターフェースがある場合は、複数のURLが表示されます：

```
  URLs:
    - http://192.168.1.10:8000/abc123def456ghi789jkl012/
    - http://10.0.0.5:8000/abc123def456ghi789jkl012/
```

表示されたURLを共有相手に伝えれば、ブラウザでアクセスできます。

## コマンドラインオプション

| オプション              | デフォルト               | 説明                       |
| ----------------------- | ------------------------ | -------------------------- |
| `--dir <path>`          | （必須）                 | 共有するディレクトリ       |
| `--port <num>`          | 8000-8100で空きを探索    | 使用するポート番号         |
| `--bind <ip>`           | 0.0.0.0                  | バインドアドレス           |
| `--interface <name>`    | なし                     | 指定NICのIPv4にバインド    |
| `--ttl <min>`           | 60                       | 最大稼働時間（分）         |
| `--idle <min>`          | 30                       | アイドルタイムアウト（分） |
| `--token <str>`         | 自動生成                 | URLトークン（24文字推奨）  |
| `--allow <cidr>`        | なし（全許可）           | 接続を許可するCIDR範囲     |
| `--max-upload-mb <num>` | 200                      | アップロード最大サイズ(MB) |
| `--log <path>`          | `<exe>\log\lan-drop.log` | ログファイルパス           |
| `--open`                | false                    | 起動時にブラウザを開く     |
| `--readonly`            | false                    | アップロードを無効化       |
| `--no-qr`               | false                    | 起動時のQRコードを表示しない |
| `--help`                | -                        | ヘルプを表示               |

## 使用例

### IP制限付きで起動

```powershell
# 192.168.1.0/24からのみアクセス許可
lan-drop.exe --dir C:\Share --allow 192.168.1.0/24

# 複数のCIDR範囲を許可
lan-drop.exe --dir C:\Share --allow "10.0.0.0/8,192.168.0.0/16"
```

### 長時間共有

```powershell
# 8時間稼働、30分アイドルタイムアウト
lan-drop.exe --dir C:\Share --ttl 480 --idle 30
```

### ブラウザを自動で開く

```powershell
lan-drop.exe --dir C:\Share --open
```

全アドレスで待ち受けている場合は `http://localhost:<port>/<token>/` を開きます。
`--bind` や `--interface` でアドレスを指定した場合は、そのアドレスのURLを開きます。

### 特定のIPアドレスにバインド

```powershell
# 特定のインターフェースのみでリッスン
lan-drop.exe --dir C:\Share --bind 192.168.1.10

# NIC名で指定（そのNICのIPv4アドレスにバインド）
lan-drop.exe --dir C:\Share --interface "Wi-Fi"
```

`--bind` に指定できるのは、このPCのNICに割り当てられたIPアドレス、`0.0.0.0`（または `*`）、`::` です。
該当しないアドレスや、存在しないNIC名を指定すると起動時にエラーになります。
`--bind` と `--interface` は同時に指定できません。

### 複数のネットワークインターフェースがある場合

全アドレスで待ち受けている場合、起動時のコンソールには共有に使えそうなIPv4アドレスを優先度順に表示します。
169.254.x.x（APIPA）や、Hyper-V・WSL・Docker・VirtualBox・VPN などの仮想NICは、他に候補があれば表示しません。
先頭には、OSがデフォルトルートに使うアドレスを表示します。

ブラウザ画面の下部に表示されるURLは、そのブラウザが実際に接続したアドレスから作ります。
このため、有線とWi-Fiのどちらから開いた人にも、その人が到達できるURLが表示されます。
localhost で開いた場合は、共有用にLAN側のアドレスを表示します。

### 固定トークン

```powershell
# 共有URLを固定したい場合
lan-drop.exe --dir C:\Share --token MySecretToken12345678
```

トークンに使えるのは英数字と `-` `_` だけです。
16文字未満のトークンを指定すると、起動時に警告を表示します。

### スマホから開く

起動時に、先頭のURLのQRコードをコンソールに表示します。
ブラウザ画面の下部にも、そのページのURLのQRコードを表示します。
コンソールに表示したくない場合は `--no-qr` を指定します。

### アップロード

ファイルを選んで「Upload」を押すか、アップロード欄にドラッグ＆ドロップします。
送信中は進捗バーを表示します。
同じ名前のファイルがある場合は `name (1).ext` のように番号を付けて保存し、既存のファイルを上書きしません。
途中で通信が切れた場合や上限を超えた場合は、そのとき送ったファイルを1つも残しません。

### 大きなファイルのダウンロード

ダウンロードは Range リクエストに対応しています。
中断したダウンロードを途中から再開でき、動画を途中から再生できます。
転送中はアイドルタイムアウトで停止しません（`--ttl` の上限は転送中でも適用されます）。

## ディレクトリ構成

```
共有ディレクトリ/
├── （ファイル群）      → ダウンロード可能
└── _uploads/         → アップロード先（自動作成）
```

- **Shared**: 指定したディレクトリ内のファイル（読み取り専用）
- **Uploads**: `_uploads/`ディレクトリ（読み書き可能）

## ログ形式

アクセスログはJSONL形式で出力されます：

```json
{"action":"start","ts":"2024-01-01T10:00:00.000Z","root":"C:\\Share","bind":"0.0.0.0","port":8000,"token":"abc...","ttl_min":60,"idle_min":15}
{"action":"access","ts":"2024-01-01T10:01:00.000Z","method":"GET","path":"/","client":"192.168.1.100","status":200,"size":1234,"ms":5}
{"action":"stop","ts":"2024-01-01T11:00:00.000Z","reason":"ttl","uptime_sec":3600}
```

ログは10MB超過時に自動ローテーション（最大5世代保持）されます。

## セキュリティ

- **Capability URL**: トークンを知らないとアクセス不可
- **パス検証**: ディレクトリトラバーサル攻撃を防止。共有フォルダ内のシンボリックリンクやジャンクションが外部を指している場合も、その先には到達できません
- **IP制限**: CIDR表記で接続元を制限可能（IPv4 / IPv6）
- **画面の保護**: ファイル名を安全に表示し、CSP（nonce）・`X-Frame-Options`・`Referrer-Policy: no-referrer` などの応答ヘッダを付けます
- **ログ**: 起動ログのトークンは伏せ字で記録します。ログファイルが共有フォルダ内にあっても公開しません
- **自動停止**: 一定時間後に自動シャットダウン

### 注意事項

- LAN内での一時的な共有を想定しています
- 公開インターネットへの露出は推奨しません
- 機密ファイルの共有には適切な注意が必要です

## トラブルシューティング

### ポートが使用中

```
Error: Port 8000 is not available on 0.0.0.0 (already in use, possibly on another network interface).
```

→ `--port`オプションで別のポートを指定してください。

### 他のPCやスマホからつながらない

ネットワークの種類が「パブリック」だと、Windows ファイアウォールが受信接続をブロックすることがあります。
該当する場合は起動時に `Warning: Network "..." is set to Public.` と表示します。
ネットワークの種類を「プライベート」に変えるか、ファイアウォールで `lan-drop.exe` を許可してください。

### アクセスが拒否される

IP制限が設定されている場合、許可されたIPからのみアクセス可能です。
ログファイルを確認して接続元IPを確認してください。

### アップロードに失敗する

- `--readonly`オプションが有効になっていないか確認
- ファイルサイズが`--max-upload-mb`を超えていないか確認
- ディスク容量を確認
